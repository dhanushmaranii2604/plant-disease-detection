About This Project

Visual Plant Disease Diagnosis Using AI

DL and ML Approaches for Agricultural Disease Detection

This project presents an AI-powered web application that detects plant diseases from leaf images using both Deep Learning (MobileNet, CNN, VGG16, VGG19) and Machine Learning (SVM, Random Forest, Decision Tree, XGBoost) approaches. By simply uploading a photograph of a plant leaf, farmers and agricultural professionals can identify diseases with high accuracy and receive treatment recommendations.

The system bridges the gap between advanced AI technology and practical agricultural use, making disease detection accessible even in remote farming communities.
