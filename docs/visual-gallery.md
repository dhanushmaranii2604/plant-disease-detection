## Usage note

Use these images in the README, presentation, or landing-page documentation to communicate the agricultural context. Do **not** use them as labelled disease examples, training data, or test data. For disease-specific evaluation, add images from a documented dataset such as PlantVillage, include the class label, and record the dataset license and source URL.

## Attribution and licensing

The images are loaded from Unsplash's image CDN for documentation display. Before using them in a deployed product, verify the current Unsplash license and attribution requirements. For a fully self-contained repository, download approved images, store them under `docs/images/real/`, and add the original photographer and source URL beside each file.
